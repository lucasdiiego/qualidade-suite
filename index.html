Este guia foi criado para ajudar você a entender a função de cada ferramenta e navegar pelas seções da aplicação com mais facilidade. Bom aprendizado e bom uso!

Fluxograma

O fluxograma ajuda a representar visualmente o caminho de um processo, mostrando etapas, decisões, documentos e conexões entre atividades. Ele é útil para entender como o processo acontece, identificar gargalos, visualizar retrabalhos e organizar melhor o fluxo de trabalho.

Como usar esta seção:

  1. Escolha um símbolo na barra lateral, como Início ou Fim, Decisão, Operação/Ação ou Documento.
  2. Clique no símbolo ou arraste-o para o quadro central.
  3. Dê duplo clique no bloco para editar o texto.
  4. Use o botão "Conectar blocos" para ligar uma etapa à outra.
  5. Selecione um bloco para ajustar texto, cor, borda, largura e altura no painel lateral.
  6. Use os botões superiores para salvar, limpar ou exportar/imprimir o fluxograma.
🔀 Fluxograma

Folha de verificação

A folha de verificação é usada para registrar dados de forma organizada, permitindo acompanhar ocorrências, inspeções e informações de um processo ao longo do tempo. Ela ajuda a padronizar a coleta de dados e facilita a análise posterior.

Como usar esta seção:

  1. Preencha os dados principais, como problema, estágio de verificação, produto e total inspecionado.
  2. Registre as informações da tabela, como turno, máquina, operador e ocorrências por dia da semana.
  3. Use "Adicionar linha" quando precisar inserir novos registros.
  4. Clique em "Calcular total" para consolidar os valores informados.
  5. Use os botões inferiores para salvar, limpar ou exportar/imprimir a folha.
📋 Folha de verificação

Histograma

O histograma é usado para visualizar a distribuição de um conjunto de dados. Ele ajuda a identificar concentração, variação, frequência dos valores e possíveis padrões no comportamento do processo analisado.

Como usar esta seção:

  1. Informe o título do gráfico.
  2. Insira os valores numéricos coletados na tabela.
  3. Defina ou ajuste o número de classes.
  4. Observe os cálculos automáticos, como amostra, mínimo, máximo, classes e incremento.
  5. Analise o gráfico gerado e a tabela de frequência por intervalo.
  6. Use os botões inferiores para adicionar valores, salvar, limpar ou exportar/imprimir o resultado.
📊 Histograma

Pareto

O gráfico de Pareto é usado para identificar quais fatores têm maior impacto em um problema. Ele organiza as ocorrências em ordem de importância e mostra o percentual acumulado, ajudando a priorizar as ações que podem gerar maior resultado.

Como usar esta seção:

  1. Informe o título do gráfico.
  2. Liste os fatores, causas ou problemas que deseja analisar.
  3. Preencha a quantidade de ocorrências de cada fator.
  4. Observe o gráfico gerado, com barras em ordem decrescente e linha de percentual acumulado.
  5. Analise a tabela com percentual individual e percentual acumulado.
  6. Priorize os fatores de maior impacto para definir as ações principais.
📈 Pareto

Gráfico de dispersão

O gráfico de dispersão é usado para analisar a relação entre duas variáveis. Ele ajuda a perceber se existe tendência, correlação ou padrão entre os dados, apoiando a interpretação de como uma variável pode se comportar em relação à outra.

Como usar esta seção:

  1. Informe o título do gráfico.
  2. Insira os pares de valores nas colunas X e Y.
  3. Escolha o tipo de linha de tendência, quando necessário.
  4. Observe a distribuição dos pontos no gráfico.
  5. Analise a equação da tendência e o valor de R², quando disponíveis.
  6. Use os botões inferiores para adicionar linhas, salvar, limpar ou exportar/imprimir o resultado.
🔵 Dispersão

Ishikawa

O diagrama de Ishikawa, também conhecido como diagrama de causa e efeito, ajuda a organizar as possíveis causas de um problema. Ele permite visualizar causas agrupadas por categorias, facilitando a investigação e a identificação dos fatores que podem estar contribuindo para a ocorrência analisada.

Como usar esta seção:

  1. Informe o problema central que será analisado.
  2. Selecione as categorias, ou Ms, que deseja utilizar no diagrama.
  3. Preencha as causas em cada categoria selecionada.
  4. Acompanhe a pré-visualização do diagrama sendo montada automaticamente.
  5. Revise as causas levantadas e organize as informações antes de avançar para a investigação da causa raiz.
  6. Use a opção de enviar as causas para a ferramenta 5 Porquês, se quiser aprofundar a análise.
🐟 Ishikawa

5 Porquês

A ferramenta 5 Porquês é usada para aprofundar a investigação de uma causa até chegar ao motivo raiz do problema. Ela ajuda a evitar análises superficiais, conduzindo o usuário por uma sequência lógica de perguntas até identificar uma ação preventiva mais efetiva.

Como usar esta seção:

  1. Importe causas da ferramenta Ishikawa ou adicione uma causa manualmente.
  2. Preencha a causa inicial que será investigada.
  3. Responda, em sequência, ao 1º, 2º, 3º, 4º e 5º Por quê.
  4. Registre o motivo raiz identificado ao final da análise.
  5. Defina uma ação para prevenir ou evitar que o problema ocorra novamente.
  6. Use os botões superiores para salvar, limpar ou exportar/imprimir a análise.
❓ 5 Porquês

Gráfico de Controle

O gráfico de controle é usado para acompanhar a estabilidade de um processo ao longo do tempo. Ele compara os valores observados com a média e os limites de controle, ajudando a identificar variações fora do comportamento esperado.

Como usar esta seção:

  1. Informe o título do gráfico.
  2. Escolha se os limites serão calculados automaticamente ou preenchidos manualmente.
  3. Insira os valores do processo na tabela.
  4. Observe o gráfico com os valores, a média, o LSC e o LIC.
  5. Analise o resumo com amostra, média, desvio-padrão e pontos fora dos limites.
  6. Use os botões inferiores para adicionar valores, salvar, limpar ou exportar/imprimir o acompanhamento.
